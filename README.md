## О проекте

Проект посвящён разработке программно-аппаратного комплекса для интеллектуального контроля качества ПЭТ-преформ непосредственно на производственном конвейере.

Основная идея — заменить ручной визуальный осмотр автоматизированным нейросетевым анализом, который позволяет обнаруживать дефекты поверхности изделий, контролировать их геометрию и формировать статистику производственного брака.

В исходной постановке проекта предполагалось применение моделей YOLO для детекции дефектов. В рамках экспериментальной работы был исследован альтернативный подход — использование сверточной нейронной сети (CNN) для классификации изображений преформ.

**Основной фокус работы:** исследование возможностей CNN-классификации, последовательное расширение датасета, анализ влияния дисбаланса классов и полноты данных на качество модели.

**Проект:** [Нейро-контроль преформ — AI Hunter](https://ai-hunter.ru/tbr2025)

## Цель проекта

Разработка промышленного прототипа системы интеллектуального контроля качества ПЭТ-преформ, способного:

- Снизить долю пропущенного брака до уровня менее 8%.
- Обеспечить охват не менее 93% производимой продукции.
- Достичь точности классификации дефектов не ниже 98%.
- Автоматизировать сбор статистики для анализа причин возникновения брака.

*Это целевые показатели промышленного проекта, а не отдельные метрики разработанного CNN-классификатора.*

## Задачи проекта

В рамках общей разработки промышленной системы были определены следующие направления:

- **Pipeline:** создание архитектуры обработки кадров от получения изображения с камеры до выдачи результата.
- **Геометрический контроль:** разработка CV-алгоритмов для измерения длины, ширины и проверки прямолинейности изделий.
- **DL-моделирование:** обучение нейросетей YOLO для детекции дефектов поверхности.
- **Интеллектуальная сегментация:** применение Oriented Bounding Boxes (OBB) для корректного выделения объектов с учётом их ориентации.
- **Мониторинг:** сбор метрик производительности и статистики брака с использованием Prometheus и Grafana.

Основные направления моей работы:

## Экспериментальное исследование

Эксперименты проводились поэтапно. На каждом этапе изменялись состав и объём датасета, а также количество распознаваемых классов.

Основная задача исследования — определить, как полнота исходных данных, распределение изображений между классами и расширение классификационной задачи влияют на качество CNN-модели.

Первый эксперимент позволил получить базовый результат и проверить применимость CNN для классификации дефектов ПЭТ-преформ.

### Эксперимент 2. Расширение до трёх классов

В датасет был добавлен третий класс — `chern_toch`.

В финальной конфигурации был добавлен класс `nedoliv`. Для расширения представления малочисленного класса применялась аугментация изображений.

## Сравнение CNN и YOLO

В рамках проекта исследовалась возможность применения CNN-классификации в качестве альтернативы детекционному подходу YOLO.

| Критерий | CNN-классификация | YOLO-детекция |
|---|---|---|
| Основная задача | Определение класса изображения | Обнаружение объектов и их локализация |
| Результат | Класс и вероятности | Координаты объектов, классы и confidence |
| Разметка | Метки классов | Bounding Boxes или OBB |
| Локализация дефектов | Не выполняется | Выполняется |
| Основное применение | Классификация подготовленных изображений | Поиск и локализация дефектов на изображении |

**Вывод:** CNN может быть альтернативой YOLO в сценариях, где объект или область интереса уже выделены, не требуется проводить детекцию и необходимо определить класс дефекта.
